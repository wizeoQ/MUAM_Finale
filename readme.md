## Инструкция для активации
В терминале bash на хосте введите:

Зайдите в директорию watchpoints

    docker build -t ros2-wp .

затем

    xhost +local:docker

потом

    docker run -it --rm \
      --env ROS_DOMAIN_ID=0 \
      --network host \
      -e DISPLAY=$DISPLAY \
      -v /tmp/.X11-unix:/tmp/.X11-unix \
      -v Путь_к_Вашему_датасету:/datasets \
      ros2-wp

Запустится папка с датасетами - помимо обычных ROS2 утилит,
также есть возможность использовать image_view и rviz2.

Для запуска lidar_subscriber.py перенесите файл в папку с датасетом, который нужно запустить, а затем введите:
'python3 lidar_subscriber.py'
